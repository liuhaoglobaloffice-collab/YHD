## 🎯 业务价值

### 用户场景

```yaml
场景1: 外贸客户语音询盘
  客户发来: [英语语音] "I need 500 tents for camping..."
  鎏灏翻译: [国语文字] "我需要500个露营帐篷..."
  鎏灏回复: [国语语音] "好的，我帮你找供应商"
  
场景2: 多语言会议记录
  参会者1: [日语] "価格はいくらですか"
  鎏灏翻译: [国语] "价格是多少？"
  参会者2: [韩语] "배송 기간은 얼마나 걸려요"
  鎏灏翻译: [国语] "交货时间要多久？"
  
场景3: 海外供应商沟通
  供应商: [德语语音] "Lieferzeit ist 30 Tage"
  鎏灏翻译: [粤语] "交货期系30日"
  老板: [粤语] "太长喇，问下可唔可以快啲"
  鎏灏翻译: [德语] "Too long, can you make it faster?"

场景4: 产品说明书翻译
  用户上传: [法语PDF] 产品说明书
  鎏灏识别: 法语 → 中文国语
  鎏灏朗读: [国语语音] "产品使用步骤..."
```

### 核心价值

- **消除语言障碍**: 外贸老板不需要会外语
- **提高沟通效率**: 实时翻译，无需等待
- **降低成本**: 不需要雇佣翻译
- **增强信任**: 用母语（国语/粤语）理解和决策

### 代码示例

```python
# 完整翻译流程
async def translate_voice(audio_file, target_lang="zh", voice_output=True):
    """
    多国语音 → 中文翻译（国语/粤语）
    
    Args:
        audio_file: 音频文件路径
        target_lang: "zh" (国语) 或 "yue" (粤语)
        voice_output: 是否语音输出
    
    Returns:
        {
            "original_text": "原文",
            "original_lang": "en",
            "translation": "译文",
            "confidence": 0.95,
            "audio_url": "语音文件URL"
        }
    """
    
    # Step 1: 语音识别
    asr_result = await whisper_transcribe(audio_file)
    original_text = asr_result["text"]
    source_lang = asr_result["language"]
    
    # Step 2: 判断是否需要翻译
    if source_lang in ["zh", "yue"]:
        translation = original_text
    else:
        # Step 3: 执行翻译
        translation = await translate_text(
            text=original_text,
            source_lang=source_lang,
            target_lang="zh"  # 先翻译成国语
        )
        
        # Step 4: 后处理
        translation = apply_terminology(translation)
        translation = to_colloquial(translation)
        
        # Step 5: 转粤语（如果需要）
        if target_lang == "yue":
            translation = mandarin_to_cantonese(translation)
    
    # Step 6: 语音合成（如果需要）
    audio_url = None
    if voice_output:
        if target_lang == "yue":
            audio_url = await vits_tts(translation, lang="yue")
        else:
            audio_url = await piper_tts(translation, lang="zh")
    
    return {
        "original_text": original_text,
        "original_lang": source_lang,
        "translation": translation,
        "confidence": asr_result["confidence"],
        "audio_url": audio_url
    }
```

## 📦 实施方案

### 方案A: 纯本地翻译（零 Token）🏆

**优点**:
- ✅ 100% 零成本
- ✅ 无网络依赖
- ✅ 数据隐私保护
- ✅ 响应速度快（< 1秒）

**缺点**:
- ❌ 翻译质量中等（BLEU 25-30）
- ❌ 需要下载模型（1-2GB per language pair）
- ❌ 对生僻词汇翻译较差

**技术选型**:
```yaml
ASR: Whisper Large-v3 (本地部署)
翻译: Helsinki NLP OPUS-MT / Facebook M2M-100
TTS: Piper (国语) + VITS (粤语)

模型大小:
  - Whisper: 3GB
  - 每个语言对翻译模型: 1-2GB
  - Piper TTS: 200MB
  - VITS TTS: 500MB
  
总存储需求: ~10GB (支持 7 种语言)
```

---

### 方案B: 云端翻译（需 Token）💰

**优点**:
- ✅ 翻译质量最高（BLEU 35-40）
- ✅ 支持更多语言
- ✅ 无需本地存储

**缺点**:
- ❌ 需要付费（$0.02-0.05 / 1K 字符）
- ❌ 依赖网络
- ❌ 数据隐私风险

**技术选型**:
```yaml
ASR: Whisper Large-v3 (本地部署)
翻译: DeepL API / Google Translate API
TTS: Piper (国语) + VITS (粤语)

成本估算:
  - DeepL: $0.05 / 1K 字符
  - Google Translate: $0.02 / 1K 字符
  
月使用量: 100K 字符
月成本: $2-5
```

---

### 方案C: 混合模式（推荐）🎯

**策略**:
```yaml
日常对话: 本地翻译
  - 客户询盘
  - 供应商沟通
  - 简单对话
  - 成本: $0

重要文档: 云端翻译
  - 合同翻译
  - 产品说明书
  - 法律文件
  - 成本: 仅在需要时付费

用户可选:
  - 设置中可切换模式
  - 单次翻译可指定引擎
  - 预览两种结果对比
```

**优点**:
- ✅ 平衡质量和成本
- ✅ 灵活可控
- ✅ 符合鎏灏"零Token"哲学

async def process_customer_inquiry(audio_message):
    # 1. 翻译客户语音

        audio_file=audio_message.audio_url,
        target_lang="zh",

    )

            target_lang=translation_result["original_lang"]
        )
    
    return reply_translated
