# 鎏灏 AI OS - 5分钟快速入门

## 1. 启动系统

```powershell
cd D:\LiuHao-AI-OS
python start_production_single.py
```

服务地址：**http://localhost:8000**

---

## 2. 登录

```powershell
$body = @{ 
    username = "admin"
    password = "admin123" 
} | ConvertTo-Json

$response = Invoke-WebRequest `
    -Uri "http://localhost:8000/api/v1/auth/login" `
    -Method POST `
    -Headers @{"Content-Type"="application/json"} `
    -Body $body `
    -UseBasicParsing

$token = ($response.Content | ConvertFrom-Json).access_token
$headers = @{ "Authorization" = "Bearer $token" }

Write-Host "✓ 登录成功"
```

---

## 3. 查看 CEO 仪表板

```powershell
$dashboardResponse = Invoke-WebRequest `
    -Uri "http://localhost:8000/api/v1/ceo/dashboard" `
    -Headers $headers `
    -UseBasicParsing

$dashboard = $dashboardResponse.Content | ConvertFrom-Json

Write-Host "`n系统状态: $($dashboard.system.status)"
Write-Host "业务任务: $($dashboard.business.total_tasks)"
Write-Host "AI员工: $($dashboard.ai_team.total_employees)"
Write-Host "待审批: $($dashboard.approvals.pending_requests)"
```

---

## 4. 创建您的第一个 AI 员工

```powershell
$employeeBody = @{
    name = "小李（AI销售）"
    department = "SALES"
    position = "销售代表"
    description = "负责客户开发"
    agent_type = "SALES_AGENT"
    provider = "openai-gpt4"
} | ConvertTo-Json

$headers["Content-Type"] = "application/json"

$employeeResponse = Invoke-WebRequest `
    -Uri "http://localhost:8000/api/v1/employees" `
    -Method POST `
    -Headers $headers `
    -Body $employeeBody `
    -UseBasicParsing

$employee = $employeeResponse.Content | ConvertFrom-Json
Write-Host "✓ AI员工创建成功: $($employee.name)"
```
