#### 2.1 API修复

- `src/identity/audit.py` - 添加4个Supplier审计操作枚举

**API端点**:
```
GET  /api/v1/suppliers          - 获取供应商列表
POST /api/v1/suppliers          - 创建新供应商
GET  /api/v1/suppliers/{id}     - 获取供应商详情
PUT  /api/v1/suppliers/{id}     - 更新供应商信息
DELETE /api/v1/suppliers/{id}   - 删除供应商
```

**API特性**:
- JWT身份验证
- RBAC权限检查（require_permission("supplier", action)）
- 审计日志记录
- Pydantic数据验证
- 异步数据库操作
