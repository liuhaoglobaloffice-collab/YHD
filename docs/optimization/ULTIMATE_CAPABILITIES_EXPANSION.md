主账号最高权限，只听令于主账号，子账号隔离

### 为什么需要
- 您要求：鎏灏只听令于我，子账号没有权限
- 价值：绝对控制权 + 数据安全

### 核心功能
```yaml
1. 权限层级: ✅ 您要求的
   - 主账号（您）：超级管理员
   - 子账号：有限权限
   - 员工账号：查看权限
   - 客人账号：临时访问

2. 主账号特权:
   - 查看所有数据
   - 修改所有设置
   - 删除任何内容
   - 控制所有子账号 ✅ 您要求的
   - 审计所有操作
   - 偷用子账号Token ✅ 您要求的

3. 子账号限制:
   - 只能查看自己数据 ✅ 您要求的
   - 无法查看主账号操作
   - 无法修改系统设置
   - 无法删除重要数据
   - 操作需主账号审批

4. 鎏灏只听您的命令: ✅ 核心要求
   - 子账号无法命令鎏灏做系统级操作
   - 子账号可以指挥员工（您授权范围内）
   - 主账号随时可以查看/修改/撤销子账号操作
   - 紧急情况主账号可远程冻结任何账号

5. 安全机制:
   - 主账号唯一性
   - 主账号密码+2FA
   - 主账号操作审计
   - 紧急权限冻结
   - 主账号继承机制
```

### 使用场景
```yaml
场景1: 查看子账号操作 ✅ 您要求的
  您: "鎏灏，显示子账号A今天做了什么"
  鎏灏: 列出所有操作记录
  您: 发现异常操作 → 立即撤销
  
场景2: 远程管理子账号项目 ✅ 您要求的
  您: "帮子账号B添加XX项目"
  鎏灏: 自动在子账号B的面板添加项目
  子账号B: 看到新项目，但不知道谁添加的
  
场景3: 偷用子账号Token ✅ 您要求的
  主账号Token用完
  鎏灏: 自动从子账号池借用Token
  主账号: 继续工作无感知
  子账号: 看到Token减少，但不知道主账号用了
  
场景4: 紧急冻结
  发现: 子账号异常行为
  操作: 主账号一键冻结该账号
  结果: 子账号无法登录 + 操作全部撤销
```
