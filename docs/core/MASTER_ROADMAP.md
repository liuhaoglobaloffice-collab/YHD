## 1. 项目概览

### 1.1 项目愿景
**LiuHao AI OS** 是一个企业级 AI 操作系统，旨在将鎏灏从 AI 辅助企业转型为 **AI 原生企业**。

### 1.2 核心目标
- 🎯 **统一 AI 接入**: 整合 6 大 AI 智能体（GPT-4o、Grok、Claude、DeepSeek、Gemini、Kimi）
- 🔐 **企业级安全**: RBAC 权限、JWT 认证、审计日志、数据加密
- 🧠 **智能决策**: AI 驱动的业务分析、自动化工作流、CEO 决策仪表板
- 🌐 **全球化**: 多租户、多语言（100+）、粤语全栈支持
- 📈 **业务赋能**: 销售、营销、运营智能体，供应商智能系统

### 1.3 技术栈
```yaml
后端: Python 3.13 + FastAPI + SQLAlchemy + PostgreSQL
AI: OpenAI GPT-4o, xAI Grok, Anthropic Claude, DeepSeek, Google Gemini, Kimi
安全: JWT (HS256), bcrypt, Fernet encryption
数据库: PostgreSQL 15+ (生产), SQLite (测试)
缓存: Redis 7+ (可选)
测试: pytest + pytest-asyncio
部署: Docker + docker-compose
前端: (待定) React/Vue/Svelte + TypeScript
```

### 1.4 当前状态
- **版本**: Y1.0 (v1.0.0)
- **开发阶段**: Week 1 Day 2
- **完成度**: 97.7% 后端测试覆盖率（471/482 tests passing）
- **剩余工作**: 7 个测试修复 + 前端开发

## 2. 架构全景

### 2.1 八层架构设计

```
┌─────────────────────────────────────────────────────────────┐
│  Layer 7: CEO 决策层 (CEO Decision Layer)                   │
│  - CEO 仪表板 | AI 驱动的决策建议 | 实时业务指标             │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│  Layer 6: 业务层 (Business Layer)                            │
│  - 销售智能体 | 营销智能体 | 运营智能体                      │
│  - 供应商智能 | 客户关系管理 | 商机分析                      │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│  Layer 5: 执行层 (Execution Layer)                           │
│  - 任务管理 | 工作流引擎 | 任务规划器                        │
│  - 自动化编排 | 进度追踪 | 资源调度                          │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│  Layer 4: 智能层 (Intelligence Layer)                        │
│  - 记忆系统 (短期/长期) | 公司大脑 (实体/事实/关系)          │
│  - 文档管理 | 知识检索 | 向量搜索 (预留)                     │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│  Layer 3: AI 运行时 (AI Runtime)                             │
│  - AI 大脑调度器 | 智能体路由 | 提供商网关                   │
│  - 6 大 AI 智能体: GPT-4o, Grok, Claude, DeepSeek,          │
│    Gemini, Kimi                                              │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│  Layer 2: 身份层 (Identity Layer)                            │
│  - 用户管理 | 角色管理 | RBAC 权限                           │
│  - 多租户系统 (预留) | 租户隔离                               │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│  Layer 1: 安全与治理层 (Security & Governance)               │
│  - JWT 认证 | 密码哈希 | 加密服务 | API 限流                 │
│  - 审计日志 | 合规检查 | 操作追踪                            │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│  Layer 0: 核心运行时 (Core Runtime)                          │
│  - 配置管理 | 日志系统 | 异常处理                            │
│  - 数据库会话 | 事件总线 (预留) | 健康检查                   │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 数据流
```
用户请求 → JWT 认证 → RBAC 权限检查 → 审计日志 → 业务逻辑
         → AI 大脑调度 → 智能体路由 → 提供商网关 → AI API
         → 响应聚合 → 知识存储 → 返回用户
```
