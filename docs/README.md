## 📝 文档编写规范

### 文档命名规则
```yaml
核心文档: UPPERCASE-WITH-DASHES.md
用户指南: 中文.md 或 Title-Case.md
技术文档: UPPERCASE.md
报告文档: PHASE-X-DESCRIPTION.md
```

### 文档结构
```markdown
# 标题

**元信息**: 版本, 日期, 状态

---

## 概览
简短介绍文档目的

## 主要内容
详细内容章节

## 总结
关键要点总结

---

**更新日期**: YYYY-MM-DD
```
