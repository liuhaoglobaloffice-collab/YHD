## 🎨 设计理念

### 核心定位
**CEO级智能指挥中心** - 专业、强大、易用

### 设计风格
- **深色主题**：减少视觉疲劳，突出数据和内容
- **卡片式布局**：信息分组清晰，易于扫描
- **数据驱动**：大量可视化图表，实时数据展示
- **AI融合**：JARVIS助手无处不在，自然交互

## 🎨 设计细节

### 颜色方案
```

- 警告色：#f59e0b (橙色)
- 危险色：#ef4444 (红色)

- 主文字：#e5e7eb (白灰色，易读)
- 次文字：#9ca3af (灰色，辅助)
- 弱文字：#6b7280 (深灰，标签)
```

### 字体系统
```
- 中文：PingFang SC / Microsoft YaHei
- 英文/数字：Inter / SF Pro Display
- 代码：JetBrains Mono
```

### 组件库
```
- 基础组件：Ant Design (React)
- 图表：ECharts / Recharts
- 表格：Ant Design Table
- 表单：Ant Design Form
- 图标：Lucide Icons + 自定义图标
```

## 📱 响应式设计

### 桌面端 (主要)
- 分辨率：1920x1080 及以上
- 布局：左侧导航 + 主内容区 + 右侧辅助
- 多任务：支持多窗口、分屏

### 平板端
- 分辨率：1024x768
- 布局：顶部导航 + 主内容区
- 手势：滑动、缩放支持

### 移动端 (轻量版)
- 分辨率：375x667 及以上
- 布局：底部导航 + 单列内容
- 功能：核心功能优先，完整功能云同步
