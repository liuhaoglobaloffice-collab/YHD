# Operations Manual

## Daily Checks

- Run the system health check and confirm core services are online.
- Inspect AI Agent status and task execution throughput.
- Inspect workflow queues and execution outcomes.
- Review security log events and access anomalies.

## Weekly Checks

- Validate data quality and knowledge access coverage.
- Confirm model registry status and model version health.
- Analyze cost and provider usage by workflow and agent.

## Monthly Checks

- Perform security audit review.
- Review permission assignments and tenant scope.
- Verify backup and recovery samples work as expected.

## Service Operations

- Record incidents, root causes, and mitigation owners.
- Confirm SLA status for P0/P1/P2/P3 events.
- Keep governance dashboard and necessary artifacts updated.
