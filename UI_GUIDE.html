🏗️ 架构说明

前端技术栈

  • • React 18 - 组件化UI框架
  • • TypeScript - 类型安全
  • • Vite - 快速构建工具
  • • Tailwind CSS - 实用优先CSS
  • • React Router - 客户端路由
  • • Zustand - 状态管理
  • • Axios - HTTP客户端
  • • Lucide React - 图标库

后端技术栈

  • • FastAPI - 现代Python Web框架
  • • SQLAlchemy - ORM
  • • Alembic - 数据库迁移
  • • Pydantic - 数据验证
  • • JWT - 身份验证
  • • RBAC - 权限控制
  • • SQLite - 数据库
  • • Uvicorn - ASGI服务器
